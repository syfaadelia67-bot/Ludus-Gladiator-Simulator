# Ludus Gladiator Simulator

Juego 2D de gestión, estrategia, intriga y combate de gladiadores para PC, desarrollado en Godot 4.

## Visión

El jugador administra un ludus: compra y forma gladiadores, asigna trabajadores, mejora instalaciones, produce equipo, investiga rivales, participa en combates 2D y asciende política y socialmente.

## Primer objetivo jugable

1. Administrar una finca básica.
2. Contratar esclavos y gladiadores.
3. Asignar trabajos.
4. Entrenar y equipar combatientes.
5. Resolver un combate 2D automático con órdenes tácticas.
6. Recibir recompensas, reputación y consecuencias.

## Tecnología

- Godot 4
- GDScript
- Datos externos en JSON
- PC como plataforma principal

Este proyecto no reutiliza código, textos, imágenes ni recursos del juego móvil utilizado como referencia de diseño.
