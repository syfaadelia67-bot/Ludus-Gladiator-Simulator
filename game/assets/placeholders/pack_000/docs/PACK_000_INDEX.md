## Convención de nombres

- `building_*`

- `prop_*`
- `structure_*`
- `ui_button_*`
- `ui_panel_*`
- `ui_bar_*`
- `ui_slot_*`
- `equipment_*`
- `status_*`
- `relation_*`
- `trait_*`

Los nombres deben permanecer estables durante el reemplazo por arte final.
