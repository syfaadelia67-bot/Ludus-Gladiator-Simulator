# Resumen de licencias — Pack 000

## Kenney

Los assets seleccionados de:

- Kenney Medieval RTS
- Kenney UI Pack
- Kenney UI Pack RPG Expansion

se distribuyen bajo Creative Commons Zero, CC0.

Los textos originales de licencia deben conservarse dentro de `licenses/`.

## Placeholders originales de Ludus

Los iconos generados específicamente para las tandas de equipamiento, estados, gestión, instalaciones, relaciones y combate pueden:

- modificarse;
- reemplazarse;
- incluirse en builds del proyecto;
- distribuirse junto con el juego.

No representan arte final.

## Material excluido

“Pack Of Medieval Tools” no forma parte del Pack 000 porque el ZIP inspeccionado no contenía una licencia verificable.

## Regla de producción

No incorporar nuevas fuentes visuales sin registrar:

1. nombre del pack;
2. autor o distribuidor;
3. licencia;
4. ruta del texto de licencia;
5. lista de archivos incorporados.
